## 1. 产品定位

**一句话**：给爸爸妈妈用的宝宝日常记录本——3 秒钟记完一件事，疫苗体检不遗漏，成长看得见。

**三条产品原则**（所有功能设计对照这三条）：

1. **记录要快**：最高频的事是"记一笔"。深夜单手、屏幕昏暗也要能操作；核心路径 ≤2 步；widget 桌面直达。
2. **提醒要准**：疫苗、补剂、体检这些"低频但不能忘"的事，App 主动推，不靠脑子记。
3. **看得见**：今天一眼汇总、日历随时回看、趋势慢慢积累（V1.1 统计）。

**不做什么**（个人家庭工具，先服务好自己家）：

- 不做社区/社交/电商/广告/账号体系
- 不做育儿内容资讯流（内置知识库 ≠ 内容平台）
- 不做"科学育儿评分"这类制造焦虑的功能

## 2. 目标用户与核心场景

**用户**：0~1 岁宝宝（设计上限覆盖 0~3 岁）的父母。主力使用者一人，家人共用一台手机或后续共享（V2）。

| 场景 | 说明 | 对应功能 |
| --- | --- | --- |
| 深夜喂奶 | 半醒状态、单手操作、不想吵醒宝宝 | 快捷记录、暗色模式、widget |
| 白天碎片记录 | 新生儿期喂奶 8~12 次/天、换尿布 6~10 次/天，单次操作必须秒级 | 快捷记录、widget |
| 交接班 | 老人/阿姨接手带娃，快速了解今天喂了几次、睡了几觉 | 今日概要、时间轴 |
| 儿保体检 | 医生问"吃多少、睡多久、大便怎么样"，要拿得出数据 | 今日概要、记录列表、（V1.1）统计导出 |
| 疫苗日 | 该打什么、打了没、下一剂什么时候 | 疫苗管理、提醒 |
| 周回顾 | 睡眠有没有规律、奶量够不够、体重涨得好不好 | 日历、（V1.1）统计与生长曲线 |

## 4. 功能需求明细

> 约定：所有记录的时间默认"现在"，均可手动改（补录）；所有记录归属某个宝宝（数据层每条记录带 `baby_id`，V1 界面按单宝宝使用）。

### FR-1 宝宝档案

- 首次启动引导录入：昵称（必填）、生日（必填）、性别、头像（本地图片或内置头像）、出生体重/身长（选填）。
- **第 N 天** = 出生当天算第 1 天，即 `今天 − 生日 + 1`；百天 = 第 100 天。口径待确认（Q-1）。
- **月龄**显示为"X 个月 Y 天"。
- 生日是全 App 的推算基础：疫苗排期、早教推荐、关键节点提醒都由它推算。

### FR-2 喂养·亲喂

- 字段：左右侧（左/右/两侧）、时长、时间、备注。
- 两种录入方式：
  - **计时器**：开始 →（换边）→ 结束，自动记左/右各自时长；
  - **手动补录**：直接填每侧分钟数。
- 首页显示"距上次喂奶 X 小时 Y 分"。
- 亲喂时长**不折算**成奶量毫升（误差太大，专业上不建议，见 Q-7）。

### FR-3 喂养·奶粉

- 字段：毫升（必填）、时间、备注。
- 输入方式：快捷档 30/60/90/120/150/180 一键选，或数字键盘自定义。
- 今日概要的"奶量"口径 = 奶粉毫升合计；亲喂单独按次数/时长统计，两者并列展示不混算。

### FR-4 换尿布

- 类型：小便 / 大便 / 都有（"干爽"不记，减少噪音）。
- 一键完成：点类型即存，无需确认。
- V1.1 增加大便性状（金黄/绿/黑，稀/软/硬，参考儿科问诊常用描述）。

### FR-5 洗澡

- 一键打卡，可选备注（如湿疹洗澡用药）。

### FR-6 睡眠

- **计时器**：开始/结束大按钮，widget 与 App 内一致；进行中在首页与 widget 常驻显示已睡时长。
- 手动补录：起止时间。
- 自动判断标签：19:00–07:00 结束的记"夜觉"，其余记"小睡"，可手动改。
- 今日概要：睡眠合计时长（含进行中）。

### FR-7 生长数据

- 三项独立录入：体重（kg，精确到 0.005，支持按"克"输入）、身高/长（cm，0.1）、头围（cm，0.1）。
- 列表按时间倒序，显示录入来源（在家/体检）。
- V1.1：WHO 2006 生长曲线（0~2 岁：年龄-身长、年龄-体重、年龄-头围、身长-体重），标 P3/P15/P50/P85/P97 百分位。

### FR-8 早教/锻炼

- 四大类：**视觉、听觉、大动作、精细动作**。
- 内置 0~12 月月龄项目库（附录 B 为示例），每项含：名称、适用月龄、一句话做法、建议频次。
- **今日推荐**：按宝宝月龄每天推 2~3 项（同一项目不连续两天重复）。
- 打卡：选项目 → 完成（时长选填）。当天打卡进"今日行程"。

### FR-9 疫苗

- 内置**国家免疫规划程序表（2021 版，附录 A）**，按出生日期自动生成接种计划（多剂次按月龄递推）。
- 每剂状态：未到月龄 / 待种 / 已种 / 不接种（如个别地区差异，可手动标"不接种"）。
- 已种记录：日期（必填）、接种点、疫苗名称与剂次（自动带出）、备注（批号等）。
- **改期**：支持把某剂拖到实际接种日，后续剂次仍按月龄规则提醒。
- 自费疫苗库（五联、13 价肺炎、五价轮状、EV71 手足口、水痘、流感等）默认隐藏，开关打开后与免费疫苗同时间线显示、标记"自费"。
- 提醒：到期前 3 天、前 1 天、当天上午 9 点（FR-13）。

### FR-10 营养补剂

- 预置常见项：维生素 D3（附提示文案：儿保常规建议出生后数日起每日 400IU）、维生素 AD、DHA、铁剂、钙、锌；支持自定义。
- 方案字段：名称、单次剂量、服用时间点（可多个）、开始日期、是否停用。
- 每日打卡：到点提醒，点一下完成；当天漏服在日历上可见。
- 多种补剂并列，各自独立打卡。

### FR-11 日历

- 月视图：每天格子下方标记录类型色点（喂养/尿布/睡眠/早教……），今天高亮，有行程的日子标行程角标。
- 点某天（含未来日期）：
  - 过去/今天：当日汇总（奶量、次数、睡眠、大小便、早教）+ 当日时间轴 + 当日行程完成情况；
  - 未来：显示计划行程（疫苗、体检、自定义）。
- 从日历可直接补录任意类型记录（选日期 + 记一笔）。

### FR-12 今日行程

"每天该做什么"都汇总在这一处，来源四类：

1. **补剂任务**（每日，可打卡）；
2. **早教推荐**（每日 2~3 项，可打卡）；
3. **疫苗计划**（临近 7 天内高亮置顶）；
4. **体检与自定义行程**（见 FR-13 关键节点）。

- 呈现：今天页"今日行程"卡（前 3 条 + 角标汇总）+ 行程 Tab 完整时间线（今天 / 即将到来 / 按月折叠的未来计划）。
- 已完成打勾；当天未完成的置灰滚动到次日（补剂漏服保留"漏服"记录）。

### FR-13 提醒通知

| 类型 | 触发 | 默认 |
| --- | --- | --- |
| 疫苗 | 到期前 3 天 / 1 天 / 当天 9:00 | 开 |
| 补剂 | 每个设定时间点 | 开 |
| 体检/自定义行程 | 提前量可选（当天/前 1 天/前 3 天） | 当天 |
| 关键节点 | 满月、百天、半岁、周岁前 1 天（文案：拍照留念 📷） | 开 |
| 喂奶/睡眠间隔提醒 | 距上次喂奶超过 N 小时（N 自定义） | 关（V1.1） |

- 全部本地通知，点击直达对应页面；总开关 + 分项开关。
- 内置体检节点：42 天、3/6/8/12/18/24/30/36 月龄。

### FR-14 桌面 Widget

三款（V1）：

| 款式 | 尺寸 | 内容 |
| --- | --- | --- |
| 快捷记录 | 2×2 | 第 N 天 + 今日奶量摘要 + 4 大按钮（奶粉/亲喂/尿布/睡眠） |
| 今日概览 | 2×4 | 左：奶量/睡眠/大小便今日汇总；右：6 快捷键（+洗澡、生长） |
| 睡眠计时 | 4×2 | 😴 进行中状态 + 已睡时长实时跳 + 开始/结束大按钮 + 距上次喂奶 |

行为约定：

- 点按钮后 **≤1 次附加点击**完成记录（尿布弹类型三选一微窗；奶粉弹毫升快捷档微窗；亲喂/睡眠直接开始计时）。
- 进行中的计时在 widget 上常驻显示。
- 深夜配色（低亮度暖色），与 App 暗色主题一致。

### FR-15 记录管理

- 时间轴/列表中的任意记录：点击查看详情，可编辑、删除（删除二次确认）。
- 补录：任意记录类型都可选过去的时间；日历选日期后新增。

### FR-16 统计（V1.1）

- 时间范围：今天 / 近 7 天 / 近 30 天。
- 内容：每日奶量与次数（奶粉 ml + 亲喂时长并列）、喂养间隔分布、大小便次数、睡眠总时长与夜觉占比、小睡分布、体重/身高/头围曲线（WHO 百分位）、早教打卡日历热图。
- 一键导出图片（发给儿保医生）+ CSV。

### FR-17 体温（V1.1）

- 录入：温度值（36.0~42.0）+ 部位（耳温/额温/腋温）+ 备注；支持发病期连续记录。
- ≥38.0℃ 温和提示（就医建议文案，不吓人）；趋势折线。

### FR-18 辅食（V1.1）

- 满六月龄自动在行程中提示"可开始添加辅食"。
- 记录：食材、量（少许/半碗/一碗）、反应（正常/疑似过敏——皮疹/呕吐/腹泻，疑似过敏高亮提醒就医咨询）。
- **新食材**标记：首次尝试的食材打"新"标签，方便排查过敏原——这是辅食期最值钱的记录。

### FR-19 数据备份

- V1：手动全量导出/导入 JSON（含档案与所有记录）；换机不丢数据。
- V1.1：定期自动备份到本地文件（Download/babycare-backup）。

### FR-20 云同步·家人共记（V1.1；Q-2 已确认必做）

爸爸妈妈两台手机都要能记，数据不能分裂。

- **同步模型**：每条记录从 V1 第一天就带 `uuid`（主键）、`updated_at`、`deleted`（软删）、`author`（哪台设备/谁记的）；同步 = 按游标增量上行/下行。V1 不联网，这些字段静默生效，V1.1 加同步零迁移。
- **冲突**：同一条记录两端都改 → 按更新时间取新者（LWW，Last-Writer-Wins）。喂养/换尿布这类"各自新增"的记录天然不冲突，LWW 足够。
- **认证**：家庭配对码换长时 token，无公开注册、无第三方账号。
- **服务端**：自建最小 Go 服务（日志型存储：上行批量收、下行按游标发；SQLite/MySQL 均可），部署在自家云服务器，HTTPS。
- **隐私与开关**：同步可整体关闭（关掉即回到纯本地，功能完整）；同步的只有记录数据本体。
- **家人共记体验**：时间轴每条记录标注记录人（妈妈/爸爸），交接班一眼看清谁记了什么。

## 5. 非功能需求

| 项 | 要求 |
| --- | --- |
| 数据 | 本地优先（Room），无账号、无网络也能完整使用；V1 可完全免联网权限 |
| 性能 | 冷启动 < 2s；widget 点击到记录完成 < 1s |
| 主题 | 亮/暗双主题，暗色偏暖黑（AMOLED 省电、深夜不刺眼） |
| 权限 | 最小化：通知（提醒）；睡眠计时用前台服务；V1.1 增加网络（仅同步用）；不申请定位/通讯录/电话 |
| 隐私 | 数据不出设备（V1）；V1.1 起同步的仅记录数据本体，走自家服务器 HTTPS，可整体关闭 |
| 多宝宝 | 数据模型预留 `baby_id`（双胞胎/二胎不用迁移数据）；V1 界面单宝宝 |
| 语言 | 简体中文；文案口语化（"该吃 AD 啦"而不是"营养补充剂摄入提醒"） |

## 8. 技术注记（非需求，开发前处理）

1. 现有工程包名 `samples.speech.cognitiveservices.microsoft.babycare` 来自模板，开发前重命名（如 `com.babycare.app`）。
2. 技术栈：Kotlin + Compose（已有）+ Material3 + Room + Glance（widget）+ WorkManager/AlarmManager（提醒）。
3. 计时类（睡眠/亲喂）跨 App 存活：前台服务 + 时间戳恢复（进程被杀后按开始时间戳还原）。
4. 同步就绪数据模型（V1 第一天落地，见 FR-20）：所有记录表 `uuid` 文本主键 + `updated_at` + `deleted` 软删 + `author`；V1.1 服务端为最小 Go 服务（上行批量、下行按游标、LWW），家庭配对码换 token。**服务端已实现：`backend/`（契约见 `docs/features/0001-biz-cloud-sync-backend/design.md`）**。
