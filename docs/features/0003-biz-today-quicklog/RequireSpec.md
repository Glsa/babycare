# RequireSpec · 今天页 + 快捷记录 + 首启档案

## 目标

把「记一笔」的核心闭环跑通：首启建档 → 今天页概览 → 快捷记录（奶粉/尿布/洗澡/亲喂手动/睡眠手动）→ 时间轴回看与编辑删除。

## 功能范围

**做**：

1. **首启引导**：无宝宝档案时全屏引导页——昵称（必填）、生日（必填，DatePicker）、性别（选填）→ 建档后进今天页；`active_baby_id` 落 meta
2. **今天页**（帧 01 结构，行程卡除外）：日期/宝宝头部（第 N 天徽章 + 月龄）、距上次喂奶、今日概要四格（奶量/睡眠/尿便/洗澡）、快捷记录五钮、今日时间轴
3. **快捷记录**：
   - 奶粉：底部弹层（快捷档 30~180 六档、±10/±30 微调、自定义时间、备注）——2 击保存
   - 尿布：三选一（小便/大便/都有），点了就存——2 击保存
   - 洗澡：一键直存
   - 亲喂：手动补录版（左/右分钟数）——**计时器是 0004**
   - 睡眠：手动补录版（结束时间 + 时长档/自定义，自动判夜觉/小睡）——**计时器是 0004**
4. **记录管理（FR-15 部分）**：时间轴条目点开详情；可创建的类型支持编辑（同弹层回填）；所有类型支持删除（二次确认，软删）
5. 时间可补录：弹层内「时间」行（快捷：现在/15分前/…/自定义 点分选择器 + 今天/昨天切换）

**不做**（后续 feature）：亲喂/睡眠计时器与前台服务（0004）、今日行程卡（行程 feature）、widget、生长/疫苗/补剂/早教的录入 UI（成长页 feature）、统计。

## 验收标准

1. 首启无档案出现引导页，建档后今天页头部显示第 N 天与月龄（口径同 AgeCalc）
2. 今天页五区块齐全且随记录实时更新（Room Flow 驱动）；距上次喂奶文案正确（跨天也对）
3. 奶粉 2 击、尿布 2 击、洗澡 1 击完成保存；保存后概要与时间轴即时刷新
4. 时间轴条目可编辑（奶粉/尿布/亲喂/睡眠/洗澡）、可删除（确认后消失）
5. 纯函数表驱动测试：TimeKit（时长/日期文案/跨天边界）、Timeline（各类型标题）、BabyInfo（解析/坏数据）全绿；`assembleDebug` 通过
