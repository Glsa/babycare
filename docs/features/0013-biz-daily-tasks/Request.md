# 0013 · 今天页重排 + 每日必做清单 — 需求录入 + 澄清

日期：2026-10-18 · 来源：用户口头需求

## 需求（三件）

1. **今天页排序**：快捷记录（瓶喂/亲喂/尿布/睡眠/洗澡）是最高频操作，提到今日早教、疫苗临近上面；今日早教提到疫苗临近上面。
2. **每日必做清单**：每天固定要做的事（吃维AD、洗脸、排气操、黑白卡、听力训练这类）像今日早教一样做成**点击完成**的形式，次日自动重新开始。
3. **早教入口收敛**：早教现在出现在今天页、行程页、成长页三处——太多。

## 拍板

| # | 问题 | 拍板 | 理由 |
| --- | --- | --- | --- |
| Q1 | 最终顺序 | 概要 → **进行中计时**（有才显示）→ **快捷记录** → **每日必做**（新）→ 补剂 → **今日早教** → **疫苗临近** → 今日行程 → 时间轴 | 高频前置：正在发生的计时最急、记一笔最常用、每日勾选次之；补剂同为每日打卡放清单后；疫苗临近是提醒性质放低；行程最低频 |
| Q2 | 每日必做的数据形态 | 新记录类型 `daily_task`（任务定义）+ `daily_task_log`（当日打卡，软删切换），复用补剂 plan/log 与早教 checkin 的现成模式 | 打卡类三兄弟（补剂/早教/必做）同构；走 records 单表天然获得备份/同步/软删 |
| Q3 | 任务从哪来 | 首次进入自动预置 5 个常用（吃维AD💊 / 洗脸🧼 / 排气操🤸 / 黑白卡⬛ / 听力训练👂），可删可加；meta 记预置标记避免删光后反复塞回 | 开箱即用；预置的一键删除不反弹 |
| Q4 | 与补剂体系的关系 | **并存不合并**：补剂有时间段提醒属性（FR-13 实装后），必做清单是纯勾选；用户想只勾不提醒就把维AD 记在清单、删掉补剂方案，自由选择 | 两套语义不同，强行合并把补剂的时间点逻辑拖进来复杂化 |
| Q5 | 与早教卡的关系 | **并存**：早教卡 = 每日轮换推荐（EduKit 算法），清单 = 固定必做项；黑白卡想每天必做就加进清单，早教卡继续推荐别的 | 推荐流和固定流是两种心智，合并任何一边都丢能力 |
| Q6 | 早教三处怎么收敛 | 今天页保留（每日推荐+打卡）；**行程页的早教卡删掉**（与今天页完全重复，且早教无时间点、不算日程）；成长页保留（早教中心：推荐+本周统计，有查看价值） | 行程页三来源卡里疫苗/补剂有日期时间属性算日程，早教没有 |
| Q7 | 打卡进不进时间轴 | 不进：时间轴保持「事件流」（喂养/尿布/睡眠），勾选类状态在各自卡片看；否则时间轴被 5×每天的任务打卡刷屏 | 时间轴信息密度优先 |
| Q8 | 管理交互 | 清单卡右上「管理」→ 弹层：任务列表（删除）+ 添加输入框；改名 V1 不做（低频，删了重加） | KISS |

## 验收

1. 今天页顺序符合 Q1；快捷记录第一屏可见（无滚动或轻滚动）。
2. 每日必做卡：勾选/取消即时生效；次日（dateKey 变化）全部回到未完成；全卡空态引导添加。
3. 首次自动出现 5 个预置任务；删除后不被塞回；可添加自定义（含 emoji 选填）。
4. 行程页不再有早教卡；成长页早教中心不受影响。
5. 备份导出含任务与打卡，导入后状态正确（records 单表天然支持）。
6. 单测：dateKey 过滤、打卡判定、预置任务、行程页无早教回归。
