# 0016 · 云同步 App 客户端 — 需求澄清（RequireSpec）

日期：2026-10-20 · 模式：逐题拍板（AskUserQuestion 已确认三项，其余沿 PRD/既有结论）

## 背景与目标

FR-20 的 App 侧落地：爸妈两台手机共记，数据不分裂。后端（0001）已完成并测试通过，本地数据层（records 单表 + LWW 判定 `SyncMerge`）自 V1 起就绪。本期补上中间缺失的一环——App 里的同步客户端：网络对接、配对流程、触发调度、状态展示。

## 已拍板决策（本期待确认项）

| # | 问题 | 拍板 |
| --- | --- | --- |
| D-1 | push 触发 | **每次写立即推**（用户原始需求）：本地每次记录变更（新增/编辑/软删）即触发上行，不攒批。异步执行，写路径不等待网络 |
| D-2 | pull 触发 | **回前台 + 前台周期 60s + 每次推送成功后顺带拉一次** |
| D-3 | 记录人标注 | **本期一起做**：时间轴记录条目显示记录人角标（数据源 = author 设备 ID + 设备名映射） |
| D-4 | 失败感知 | **静默重试（指数退避）+ 我的页可查**（上次成功时间/失败原因小字）；记录操作永不因同步失败受阻或弹全局提示 |

## 功能范围

### 做

1. **同步引擎**：push（脏记录分批上行）/ pull（游标增量）/ LWW 合并（复用 `SyncMerge`）/ 本地游标与脏记录跟踪 / 失败退避重试
2. **配对与家庭**：创建家庭（主设备）、输配对码加入（第二台）、刷新配对码、设备列表、断开同步（回到纯本地）
3. **服务器配置**：手动输入后端地址（自建服务，无发现机制）
4. **首次绑定全量上行**：已有历史记录绑定后分批推完（≤500/批）
5. **记录人标注**：时间轴/今日列表显示「谁记的」角标
6. **同步状态可查**：我的页显示上次同步成功时间、失败原因
7. **同步总开关**：关闭即回到纯本地，功能完整；重开后继续同步（PRD FR-20 隐私与开关）

### 明确不做

- 服务端实时推送（FCM 等）——纯拉取模型，延迟见 D-2
- 亲喂计时暂态（meta 表）不同步——换机恢复「进行中」计时无意义（0010 Q4 同结论）
- 墓碑物理清理——后端 V2 事项
- 多宝宝界面、共享范围管理——V2.0
- 自动备份（0010 灰置项，另立课题）

## 非功能需求

- **本地优先**：断网/后端宕机时记录功能 100% 可用；同步是纯后台旁路
- **写路径零阻塞**：任何记录操作不 await 网络，失败不影响 UI
- **数据正确性**：LWW 判定与后端、导入导出（0010）同一语义（`updated_at` 严格大于才覆盖）
- **安全**：token 不落日志；HTTPS 为默认预期（自建后端已含部署说明）
- **电量**：周期 pull 仅在 App 前台可见时运行，退后台即停

## 约束与依赖

- API 契约以 `docs/features/0001-biz-cloud-sync-backend/design.md` §3 为准（字段名、错误码、批量上限 500、payload ≤64KB）
- Room schema 若加脏跟踪列需写迁移；设置类数据（地址/token/开关/游标）走 SharedPreferences（0010 Q2 先例，不进 Room）
- 头像若为本地图片文件则不同步图片本体（payload 只含 JSON）——设计阶段核对 `baby_profile` payload 结构后定论
- AndroidManifest 需补 `INTERNET` 权限（V1 免联网，可能未声明——实现时核对）
- HTTP 客户端选型、脏跟踪实现方式、模块划分 → design.md 决定

## 验收标准

1. **共记**：两台设备 A/B 绑定同一家庭；A 记一笔 → B 前台 60s 内可见；B 删除 → A 侧对应记录消失（软删同步）
2. **每次写即推**：A 记一笔，后端收到该笔上行（服务端日志/抓包可证）；push 不阻塞 UI
3. **冲突 LWW**：两端先后改同一条记录 → 两端最终一致，均为 `updated_at` 较新版本
4. **断网补推**：断网记 10 笔 → 恢复后自动全部补推，无丢失；重试期间无 UI 打扰
5. **首次绑定**：已有 ≥500 条历史记录的设备绑定后全量分批上行完成
6. **配对流程**：创建家庭 → 拿到配对码 → 第二台输码加入 → 设备列表显示两台；配对码过期有明确报错
7. **开关**：关闭同步后纯本地完整可用；重新开启后增量续传（游标不丢）
8. **记录人角标**：时间轴显示另一台设备记录的条目角标（设备名）
9. **状态可查**：我的页显示上次同步成功时间；失败时显示原因小字
10. **单测**：LWW 合并、游标推进、脏跟踪、请求/响应 JSON 与后端契约字段对齐，全绿
