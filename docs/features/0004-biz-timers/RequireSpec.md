# RequireSpec · 计时类

## 目标

亲喂/睡眠从「手动补录」升级为「1 击开始计时」：计时状态跨进程存活，首页卡片与前台通知双处常驻可见。

## 功能范围

**做**：

1. **亲喂计时器**（FR-2 计时器路径）：点「亲喂」→ 选左/右开始；进行中卡片显示左/右各自实时分钟（已累计 + 当前段）；换边（自动结一段开另一段）；暂停/继续；结束 → 自动生成 feed_nursing 记录（左右分钟，四舍五入到分钟）；取消（丢弃不存）。手动补录入口保留
2. **睡眠计时器**（FR-6）：点「睡眠」直接开始；进行中卡片显示已睡时长 + 开始时间；结束弹层（结束时间默认现在可改、夜觉/小睡按结束小时自动判且可改、备注）→ 落定 sleep 记录；取消（确认后丢弃）
3. **前台服务**：计时期间常驻通知（实时时长、点开进 App、通知按钮直达 换边/结束/暂停）；两个计时可并行（喂睡同哄）；进程被杀后重开 App 按时间戳恢复计时与通知
4. **权限**：首次开始计时请求通知权限（API 33+）；拒绝也能计时（只是不显示通知）

**不做**（后续 feature）：widget、深夜态、睡眠结束智能建议、喂奶间隔提醒。

## 验收标准

1. 亲喂选边 1 击开始；换边/暂停/结束各自 1 击；结束后生成的记录与手动补录口径一致（时间轴可查可编辑）
2. 睡眠 1 击开始；结束弹层默认现在、标签自动判且可改；**跨天夜觉**（23:10 开始、次日 02:15 查看）卡片正确显示已睡时长
3. 进行中状态首页卡片 + 前台通知双处可见且实时；通知按钮操作在 App 退到后台时生效
4. 计时状态不因进程死亡丢失：杀掉 App 重开，卡片与通知按开始时间戳还原
5. 纯函数测试：计时累计（换边/暂停/跨段）、亲喂分钟换算、状态 JSON 往返全绿；`assembleDebug` 通过
