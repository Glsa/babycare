# Request · 计时类：亲喂计时器 + 睡眠计时器（前台服务）

## 背景

0003 已交付亲喂/睡眠的手动补录。PRD FR-2/FR-6 的另一半是**计时器**：1 击开始、亲喂换边/暂停自动分段、结束自动记时长；且要求跨 App 存活（前台服务 + 开始时间戳恢复，PRD §8）与进行中状态首页常驻（FR-6）。widget 的睡眠计时（FR-14）后续 feature 直接复用同一状态源。

## 要什么

1. **亲喂计时**：点「亲喂」→ 选左/右 1 击开始；换边自动分段累计；暂停/继续；结束自动分记左右分钟
2. **睡眠计时**：点「睡眠」1 击开始；结束时结束时间可调、自动判夜觉/小睡
3. **进行中卡片**：首页常驻显示已睡/已喂时长（实时跳），支持结束/换边/暂停/取消
4. **跨进程存活**：前台服务常驻通知（显示已进行时长 + 快捷按钮），进程被杀后按开始时间戳恢复
5. **通知快捷操作**：亲喂（换边/结束）、睡眠（结束）

## 不做（后续 feature）

Widget 三款（Glance，读同一计时状态）、深夜态（帧 09）、提醒推送（疫苗/行程）
