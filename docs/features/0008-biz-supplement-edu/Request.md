# Request · 补剂 + 早教 + 行程回填

## 背景

0006 行程把骨架搭好（今日行程卡 + 行程 Tab 三段分区），当时预留的补剂/早教/疫苗三类来源没接；0007 成长页落地了生长+疫苗。本 feature 补齐成长域剩下的两块——补剂（FR-10）、早教（FR-8），并把三类来源回填进今日行程卡与行程 Tab（FR-12 的「今日待办」闭环）。

## 要什么

1. **补剂方案**：预置常见补剂（VD3 带 400IU 提示文案 / AD / DHA / 铁 / 钙 / 锌）+ 自定义；方案字段＝名称 / 单次剂量 / 每日时间点（多个）/ 开始日期 / 停用。
2. **补剂每日打卡**：每个进行中的方案 × 每个时间点 = 一个当日任务，各自独立打勾/取消；打卡生成补剂记录，时间轴可见（漏服=没打卡，天然可回看）。
3. **早教项目库**：内置 0~12 月四类项目（视觉/听觉/大动作/精细动作，附录 B 细化为完整库）。
4. **早教今日推荐**：按月龄每天 2~3 项，同一项目不连续两天重复；点推荐即打卡（时长选填，可后补编辑）；当天打卡进今日记录时间轴。
5. **成长页早教中心卡**：本月推荐 + 本周打卡次数（帧 06 第三段）。
6. **行程回填**：
   - 今日行程卡 & 行程 Tab：补剂任务、早教推荐进入「今天」；疫苗临近 7 天内置顶（点击跳成长页去标已种）
   - 行程 Tab 补剂卡带「管理」入口（方案增删改、停用）

## 不要什么（明确不做）

- 到点提醒 / 通知（FR-13 整体延后；时间点先只做展示与打卡口径）
- 补剂库存 / 余量 / 用完提醒（PRD 无此要求，确认不做）
- 早教自定义项目、项目库编辑（V1 只读内置库；附录 B 即完整库）
- 早教历史统计页（成长页只放「本周打卡次数」一个数字）
- 补剂打卡记录的编辑弹层（时间轴里补剂记录只读+删除；改打卡=取消再打）

## 验收（给 RequireSpec 用）

1. 建一个 VD3 方案（09:00/21:00 两个时间点）后，今天卡与行程 Tab 出现两条任务，各自打勾/取消独立生效，时间轴出现 💊 记录
2. 停用方案后当日任务消失；开始日期在未来的方案不出现；改时间点后任务跟着变
3. 早教推荐按月龄出 2~3 项、同一天内容稳定、与昨天不重复；打卡后今日记录时间轴出现 🎨 记录，卡片状态即时翻转
4. 疫苗临近 7 天（含已到期）在今日行程卡与行程 Tab 置顶展示，点击跳成长页
5. 成长页早教中心卡显示本月推荐与本周打卡次数
6. 纯函数测试全绿 + assembleDebug 通过
