# 0011 · 喂奶间隔倒计时 — 需求澄清（RequireSpec）

日期：2026-10-18 · 模式：逐题拍板

## Q1 倒计时显示在哪？

**拍板：今天页头部，「距上次喂奶」badge 旁并排第二个 badge；Widget 不加。**

- 理由：头部已有「距上次喂奶」badge（30 秒心跳驱动），倒计时与它是同一时刻的两种表述，并排最自然、零新增布局。Widget 空间紧（今日概览右列六键占满），加了反而挤，以后有需要再回填。

## Q2 间隔按什么时刻判定白天/夜晚？

**拍板：按「这次喂奶开始」的时刻判定，不是看倒计时到点时是几点。**

- 理由：晚上 20:00 那顿按夜晚间隔（比如 4h，撑到凌晨），早上 7:30 那顿按白天间隔（3h）——间隔服务于「这顿之后多久吃下一顿」，由这顿发生时段决定最直观。倒计时跨过昼夜分界线不改变本轮间隔。

## Q3 设置项与默认值？

**拍板：四项，我的页一行入口 + 弹层编辑。**

| 项 | 默认 | 输入 |
| --- | --- | --- |
| 白天间隔 | 3 小时 | 小时（可输小数，如 3.5） |
| 夜晚间隔 | 3 小时 | 同上 |
| 白天从几点 | 7 点 | 0–23 整点 |
| 夜晚从几点 | 19 点 | 同上 |

- 存储换算成分钟（`dayMin=180` 等），内部不做小数运算。
- 白天时段 = [白天起, 夜晚起)，夜晚 = 其余；校验两个起点不相等（相等视为非法，保存按钮置灰）。

## Q4 设置存哪？

**拍板：SharedPreferences 单 key 存 JSON（与深色开关同层）。**

- 理由：设置不是业务记录，不进 Room；V1 云同步不传设置（爸妈各自设备的偏好），将来要同步再迁 meta。换机/清空不随备份走，重设一次的成本可接受。

## Q5 展示文案与超时态？

**拍板：**

- 进行中：`⏱ 距下次喂奶 1:23`（badge 用现有喂奶色）
- 已超时：`🍼 该喂奶了 · 超 0:12`（红色 badge，分钟粒度）
- 今天还没有喂奶记录且无进行中亲喂：不显示 badge
- 进行中亲喂：从亲喂 `startAt` 起算（奶已经开始，倒计时已在走；取「亲喂计时开始时刻」与「最近一条喂奶记录」的较大者）

## Q6 提醒通知做不做？

**拍板：不做，纯展示。** 到点弹通知是 FR-13（提醒）的一部分，实装时把「喂奶间隔到点」纳入提醒矩阵即可，本轮数据与文案已就绪。

## 验收标准

1. 今天页头部显示倒计时 badge，随 30 秒心跳刷新；无喂奶记录时不显示。
2. 默认白天/夜晚各 3 小时，装完即用，无需先去设置。
3. 我的页改间隔/分界后保存，今天页立即按新值显示。
4. 白天/夜晚按喂奶开始时刻正确判定（含分界边界 7:00、19:00、跨午夜）。
5. 超时态红色「该喂奶了 · 超 X:XX」。
6. 进行中亲喂从开始时刻起算。
7. 单测覆盖昼夜判定与文案（在 76 基础上新增）。
