# 0011 · 喂奶间隔倒计时 — 需求录入

日期：2026-10-18 · 来源：用户口头需求

## 需求

从**开始喂奶**的时刻起，显示「距下次喂奶」倒计时，到点提示该喂了。

1. 默认间隔 3 小时，可调整
2. 白天 / 夜晚间隔**独立设置**（夜里想拉长间隔让宝宝睡整觉是常见场景）
3. 昼夜分界时间也应可设（各家作息不同）

## 涉及

- 今天页头部：现有「距上次喂奶」badge 旁加倒计时 badge（超时红色）
- 我的页：新增「喂奶间隔」设置行 + 编辑弹层（间隔 + 昼夜分界）
- 倒计时是**纯展示**，不弹通知（通知属 FR-13 提醒，仍 parked）

## 范围

做：App 内今天页倒计时展示 + 我的页设置。
不做：Widget 端展示（今日概览 4×2 以后要加再说）、到期通知（FR-13 实装时做）、按需/按时喂奶模式切换。
