# RequireSpec · 行程

## 目标

「该做什么」的第一块主干：自定义/体检行程可建可勾可回看，今天页能看到今天的行程，日历未来日能看到计划。

## 功能范围

**做**：

1. **行程 Tab**（替换占位）：
   - **今天**：当天行程列表，行内圆钮点一下 = 完成/取消完成（再点取消）；空则显示「今天没有行程」
   - **即将到来**：明天起 7 天内的行程（含第 7 天），显示「周几 · HH:mm」
   - **未来计划**：第 8 天起按月分组，默认折叠，点月标题展开/收起
   - 右上角 ＋ 打开新建弹层；点行程条目 → 详情弹层（编辑/删除，与其他记录一致）
2. **行程弹层**（新建/编辑）：标题必填；类型 chips「体检 / 自定义」；日期（DatePicker，默认明天）+ 时间（TimePicker，默认 10:00）；备注选填。编辑时回填原值
3. **今天页今日行程卡**（今日概要卡下方）：标题「今日行程」+ 前 3 条（完成态 + HH:mm + 标题）+ 底部「剩 N 项待办 · 查看全部」；当天无行程整卡不显示；点卡片跳行程 Tab
4. **体检自动生成**：建档后按生日生成 42 天 + 3/6/8/12/18/24/30/36 月龄共 9 条体检行程（时间 10:00）；只在首次出现该宝宝时生成（幂等，不因重启重复）；生成后与自定义行程同样可编辑/删除/打勾
5. **日历未来日**：选中未来日显示该日计划行程列表（时间 + 标题 + 类型徽章，可点开编辑）；无计划显示「这天还没有计划」

**不做**：提醒通知、补剂/早教/疫苗来源、行程角标、往期行程专区（历史在日历/时间轴看）。

## 验收标准

1. 新建一条明天的「儿保体检」：出现在行程 Tab「即将到来」与日历该日；编辑改到下周 → 移入「未来计划」对应月份组
2. 今天的行程在今天卡与行程 Tab 都显示；点圆钮打勾后两处同步变完成态；再点可取消
3. 删除行程后各处即时消失
4. 新建档宝宝后，9 条体检按生日生成一次；杀进程重开不重复生成；手动删掉一条体检后重开 App 不再补回
5. 纯函数测试：分组边界（今天/第 7 天/第 8 天/跨月分组）、体检节点日期（42 天 = 生日 + 41 天）全绿；`assembleDebug` 通过
