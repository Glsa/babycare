# Request · 行程（今日行程卡 + 行程 Tab）

## 背景

FR-12「今日行程」：今天页有「今日行程」卡（前 3 条 + 汇总角标），行程 Tab 是完整时间线（今天 / 即将到来 / 按月折叠的未来计划）。目前两处都是占位。0005 日历的未来日空态也留着「行程功能上线后回填」的钩子。

行程的完整来源有四类（补剂 / 早教 / 疫苗 / 体检与自定义），前三类随「成长」feature 才有数据，本 feature 先落**体检 + 自定义行程**这条主干。

## 要什么

1. **行程 Tab**：今天（打勾完成）→ 即将到来（未来 7 天）→ 未来计划（按月折叠）；右上角 ＋ 新建行程；点条目看详情，可编辑/删除
2. **新建/编辑行程弹层**：标题、类型（体检/自定义）、日期、时间、备注
3. **今天页今日行程卡**：今日行程前 3 条 + 未完成汇总，点卡片跳行程 Tab；当天没行程不显示
4. **体检自动生成**（附录 C）：42 天 + 3/6/8/12/18/24/30/36 月龄体检，按生日自动生成，可勾选完成；重复打开 App 不重复生成
5. **日历未来日回填**：选中未来日显示当天计划行程（替换 0005 的空态文案）

## 不做（后续 feature）

- 提醒通知（FR-13 整体延后，`remindDaysBefore` 字段已留）
- 补剂 / 早教 / 疫苗三类来源（随成长 feature 回填到行程页分区与今日行程卡）
- 日历月视图行程角标（AGENDA 类型色点已能表示，角标等四类来源齐了再说）
