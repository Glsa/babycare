# Request · 成长（生长 + 疫苗）

## 背景

成长 Tab（🌱）还是占位页。PRD 里成长域四块：生长（FR-7）、早教（FR-8）、疫苗（FR-9）、补剂（FR-10）。四块塞一个 feature 太大、不好验收，切成两刀：

- **0007（本 feature）＝ 生长 + 疫苗**：记录查看类，长在成长页上，产出成长页主体（帧 06 前两段）。
- **0008（下一个）＝ 补剂 + 早教 + 行程回填**：打卡类，并把这补剂/早教/疫苗三类来源回填进今日行程卡与行程 Tab。

## 要什么

1. **生长录入**：体重/身高/头围三项独立录入（一次可只填其中几项），来源「在家/体检」；体重按克输入（对应 PRD 0.005kg 精度），身高/头围按厘米 0.1 步进。
2. **生长数据卡**：成长页顶部展示三项最新值 + 记录日期（如 6.4 kg · 10月12日）。
3. **生长记录列表**：按时间倒序，显示数值与来源，点开可编辑/删除。
4. **疫苗计划**：免疫规划疫苗（附录 A，22 剂）按生日自动排期，纯函数推导、不生成记录；每剂状态：未到月龄 / 待种 / 已种 / 不接种。
5. **已种录入**：点某剂 → 填接种日期（必填，默认今天）、接种点、备注/批号；疫苗名称与剂次自动带出。不接种也可标记。晚种不改变后续排期（始终按月龄推）。
6. **疫苗进度卡**：已种 X/22 + 进度条 + 下一剂提示（名称 + 日期）。
7. **成长页整页**：替换占位页（生长数据卡 → 生长记录 → 疫苗进度 → 剂次列表）。
8. **时间轴打通**：今天页/日历时间轴里的生长、疫苗记录详情可编辑、删除（现在只读）。

## 不要什么（明确不做）

- 补剂、早教（含早教中心卡）→ 0008
- 疫苗/补剂/早教来源回填今日行程卡与行程 Tab → 0008
- WHO 生长曲线 → V1.1
- 自费疫苗库（默认隐藏＝V1 直接不展示）
- 接种提醒通知（FR-13 整体延后）

## 验收（给 RequireSpec 用）

1. 成长页能看到三项最新生长数据 + 记一笔生长（只填体重也行）成功，列表倒序出现
2. 22 剂按生日排期正确（乙肝①在生日当天、3 月龄在 11月10日 这类），改生日后跟着变
3. 标已种（改日期/接种点/备注）后状态与进度即时更新；不接种标记后不计入已种；删除记录后回到待种/未到月龄
4. 晚种不影响后续剂次排期（排期永远按生日月龄推）
5. 时间轴里生长/疫苗记录可编辑可删除
6. 纯函数测试全绿 + assembleDebug 通过
