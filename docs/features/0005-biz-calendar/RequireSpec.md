# RequireSpec · 日历页

## 目标

「看得见」的第二块：月视图一眼看清哪天记了什么，点开回看当日明细，顺手补录漏记的。

## 功能范围

**做**：

1. **月视图**：周一开头 7 列网格；每天格子 = 日期数字 + 下方类型色点（当天有哪些类型就有哪些点，最多显示 5 个）；今天 = 主色实心圆；选中其他日 = soft 底圆；月份 ‹ › 翻页 +「今天」快捷回当月
2. **选中日卡**（过去/今天）：标题（10月15日 周四 · 第 N 天）+ 当日汇总卡 + 当日时间轴（点条目 → 详情弹层，可编辑/删除，与今天页一致）
3. **日历补录**：选中过去/今天时显示快捷记录条（五类），点开对应补录弹层，**时间默认落在选中日**（弹层内可再调时分）；睡眠/亲喂为手动补录表单（计时器只在今天页）
4. **未来日**：可选中，显示「这天还没有计划」空态（行程 feature 上线后回填）；不可补录
5. 未选中任何天时：不显示日卡（只看月视图）

**不做**：行程角标/计划列表、统计、其他类型的补录。

## 验收标准

1. 月视图色点正确反映当天记录类型（多类型多点）；今天高亮随系统日期
2. 选中过去日：汇总数字与时间轴与该日实际记录一致；第 N 天按生日推算正确
3. 从日历补录一条奶粉（默认时间 = 选中日）：保存后出现在该日时间轴，月视图色点即时多出喂养点
4. 日历内编辑/删除记录后，时间轴与色点即时刷新
5. 纯函数测试：月视图矩阵（周一开头/行数/跨月边界）、按日聚合类型 全绿；`assembleDebug` 通过
