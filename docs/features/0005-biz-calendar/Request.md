# Request · 日历页（月视图 + 日详情回看）

## 背景

FR-11：日历月视图回看每天的记录情况，点开某天看当日汇总与时间轴，并可从日历直接补录。今天页（0003）只覆盖「今天」，历史记录回看缺一个入口。

## 要什么

1. **月视图**：每天格子下方标记录类型色点（一类型一点），今天高亮，月份前后翻页 + 快速回当月
2. **点某天**：
   - 过去/今天：当日汇总（复用今天页的 SummaryCard）+ 当日时间轴（可点开编辑/删除，复用现有弹层）
   - 未来：显示计划行程（行程数据 V1 后续 feature 才有，先空态占位）
3. **日历补录**：选中过去/今天后可直接补一笔（五类：奶粉/尿布/洗澡/亲喂手动/睡眠手动），记录时间默认落在选中日

## 不做（后续 feature）

行程角标与未来日计划列表（行程 feature 回填）、统计图表（V1.1）、生长/疫苗/补剂在日历的补录（成长页 feature）。
