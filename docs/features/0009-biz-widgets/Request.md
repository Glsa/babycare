# Request · 桌面 Widget 三款

需求来源：PRD FR-14、UI 设计说明 §4（帧 08）、全局 Q-5（先做三款）。

## 要什么

1. **快捷记录 2×2**：第 N 天 + 今日奶量摘要（如 780 ml · 8 次）+ 四大圆钮（奶粉/亲喂/尿布/睡眠）
2. **今日概览 4×2**：左列今日汇总（奶量/睡眠/大小便），右列 6 快捷键（+洗澡、生长）
3. **睡眠计时 4×2**：进行中状态（😴 + 实时时长 + 开始时间 + 距上次喂奶 + 结束大按钮）；未睡时显示开始
4. 点按钮 ≤1 次附加点击完成记录；睡眠开始/结束在 widget 上直接完成
5. 亮暗两套配色，与 App 主题一致（深夜低亮度暖色）

## 为什么

- 最高频路径是「记一笔」：喂奶 8~12 次/天、换尿布 6~10 次/天，桌面直达是 PRD 第一设计原则（FR-1）
- 深夜半醒场景：不解锁进 App 也能看到睡眠时长/开始睡眠

## 不做（本轮）

- 第四款「亲喂专用」widget（Q-5 拍板：先三款看使用习惯）
- 锁屏/多桌面差异化、每实例独立数据（三款都是全局单宝宝数据）
- Glance 原生弹窗微窗（奶粉档位/尿布三选一走 App 弹层，见 RequireSpec Q2）
- API 26~30 的精细预览图（用简易色块预览，31+ 用真实布局预览）
