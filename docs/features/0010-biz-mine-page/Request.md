# 0010 · 我的页 — 需求录入

日期：2026-10-18 · 来源：PRD FR-1/FR-13/FR-15/FR-19 + UI 设计稿帧 07（nodeId 7:2）

## 背景

V1.0 最后一个主页面（前序：骨架/今天/计时/日历/行程/成长/补剂早教/Widget 均已完成）。「我的」承载宝宝档案编辑、外观与数据管理，是 V1 收口页。

## 设计稿结构（帧 07，自上而下）

1. 标题「我的」
2. **宝宝档案卡**：👶 头像 + 昵称 + 「生日 · 性别 · 第 N 天」+「编辑 ›」按钮
3. **提醒设置**行：🔔 提醒设置 · 疫苗 · 补剂 · 节点
4. **深色模式**行：🌙 深色模式 · 跟随系统 + 开关
5. **功能卡**：📊 统计与生长曲线（灰）/ ☁️ 自动备份（灰）/ 💾 导出数据 / 📥 导入数据
6. **危险卡**：🗑️ 清空所有数据 · 不可恢复（红）
7. 底部提示：🔒 所有数据仅保存在本机，可随时导出备份

## 需求点（对应 PRD）

| 需求 | PRD | 说明 |
| --- | --- | --- |
| 宝宝档案编辑 | FR-1 | 昵称/生日必填，性别/出生体重/出生身长选填；建档时只收了前三样，编辑处补全 |
| 提醒设置入口 | FR-13 | 提醒实装（疫苗/补剂/节点通知）此前已 park；本期只放入口 |
| 深色模式 | — | 当前 App 跟随系统，无手动开关 |
| 导出数据 | FR-19 | V1 手动全量导出 JSON（档案 + 全部记录） |
| 导入数据 | FR-19 | 换机/误删恢复；需与现有数据合并 |
| 统计 / 自动备份 | FR-16 / FR-20 | V1.1，灰置展示 |
| 清空数据 | FR-15 | 危险操作，需强确认，清完回到首启引导 |

## 范围

- 做：上述设计稿全部区块（灰置项只做展示态）
- 不做：FR-13 提醒实装（独立课题）、统计页、云同步开关、多宝宝
