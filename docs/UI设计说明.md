## 2. 设计规范（tokens）

### 2.1 颜色

Figma 里有变量集「颜色」（亮色模式），共 25 个 token，全部色值绑定变量（改 token 即全局换肤）。分三组：

| 组 | token | 色值 | 用途 |
| --- | --- | --- | --- |
| 基础 | `bg` `surface` `surfaceAlt` `divider` | #FAF6F3 #FFFFFF #F4EDE8 #EFE7E1 | 页面底 / 卡片 / 卡内条目底 / 分割线 |
| 文字 | `text1` `text2` `text3` | #3D3633 #8C817B #C2B6AE | 主文 / 次文 / 弱化（日期、占位） |
| 主色 | `primary` `primarySoft` | #E8697A #FBE8EB | 主按钮 / 主色底 |
| 类型色 | `feed`+`Soft` | #E3A246 #FCF1DF | 奶粉·喂养（橙） |
| | `nurse`+`Soft` | #E8697A #FBE8EB | 亲喂（与主色同源粉） |
| | `diaper`+`Soft` | #66BA95 #E5F4EE | 尿布（绿） |
| | `sleep`+`Soft` | #7D9BE8 #E9EEFA | 睡眠（蓝） |
| | `bath`+`Soft` | #5BBED4 #E3F4F8 | 洗澡（青） |
| | `growth`+`Soft` | #A78BDB #F0EAF8 | 生长（紫） |
| | `edu`+`Soft` | #E8865C #FCEAE1 | 早教（橘红） |
| | `vaccine`+`Soft` | #D9534F #FBE7E6 | 疫苗（红，警示语义） |

每个类型色配一个同色系浅底（`xxxSoft`）做卡片底/胶囊底，保证「类型色」在页面上一眼可辨但不刺眼。

**暗色板**（帧 09 使用的整组替换值）：底 #161210、卡 #221C19、次底 #2B2420、分割 #332B27、文字 #F0E9E4 / #A79C95 / #6E645E、主色 #E8808F，各类型色整体提亮一档、Soft 底换成同色系深底（如 sleepSoft #282E42）。偏暖黑，深夜不刺眼，AMOLED 省电。

### 2.2 字体 / 圆角 / 间距

- 字体：Noto Sans SC（Regular / Medium / Bold 三档，中文友好）
- 字号阶梯：28（大数字，如"150 ml"）/ 20（页标题）/ 16（卡片标题）/ 13~14（正文）/ 11（辅助说明）
- 圆角：卡片 20、按钮/胶囊 12~14、小 chip 10、底部弹层顶角 24
- 间距：4 的倍数网格；卡片内边距 16，页面左右边距 20，卡片间距 12
- 画板 360×800（含底部导航），底部弹层遮罩 35% 黑

## 3. 三个核心交互

### 3.1 记录要快：3 秒路径

所有高频记录的路径长度（对应 PRD「核心路径 ≤2 步」）：

| 记录 | 路径 | 步数 |
| --- | --- | --- |
| 奶粉 | widget/App 点「奶粉」→ 弹层点快捷档（如 150）→ 自动保存 | 2 击 |
| 尿布 | 点「尿布」→ 三选一微窗（尿/便/都有） | 2 击 |
| 亲喂 | 点「亲喂」→ 选左/右开始计时（换边/结束再点） | 1 击开始 |
| 睡眠 | 点「睡眠」→ 开始；结束时点一下 | 1 击开始 |
| 洗澡/生长 | 洗澡一键；生长进弹层填数值 | 1 击 / 3 击 |

设计上把这五类做成**首页常驻快捷条**（大图标+文字，单手拇指可达），且 widget 上同样有（见 §4）——最高频的事在哪儿都是一步触达。

### 3.2 深夜单手（帧 09）

凌晨喂奶场景的完整暗色态：状态栏/导航跟随暗色、类型色降饱和、**睡眠进行卡置顶常驻**（夜觉 23:10 开始 · 已睡 3 小时 05 分 · 点按结束），时间轴只显示今晚记录。开发时暗色不单独设计一版，全靠 token 替换（§2.1 暗色板）。

### 3.3 每天该做什么：今日行程（帧 05 + 帧内今日行程卡）

四类来源汇成一处，按「今天 → 即将到来 → 更远的计划」分层：

1. **补剂任务**：VD3 已服 ✅ / DHA 待服 ⏰ + 打卡按钮
2. **早教推荐**：按月龄每天 2~3 项，可打卡（黑白卡追视 ✅ / 俯卧抬头 ⏳）
3. **临近疫苗**：7 天内置顶高亮（11-10 脊灰②+百白破①，红底）
4. **体检与节点**：3 月龄儿保、百天拍照（主色底）

今天页只露前 3 条 + 汇总角标，完整时间线在「行程」Tab。

## 4. Widget 三款（帧 08）

| 款式 | 尺寸 | 内容 | 点击行为 |
| --- | --- | --- | --- |
| 快捷记录 | 2×2 | 第 69 天 + 今日奶量（780 ml · 8 次）+ 四大圆钮（奶粉/亲喂/尿布/睡眠） | 四钮直达对应记录（≤1 次附加点击完成） |
| 今日概览 | 2×4 | 左列今日汇总（奶量/睡眠/尿便），右列 6 快捷键（+洗澡、生长） | 快捷键直达记录 |
| 睡眠计时 | 4×2 | 😴 睡眠中 + 实时时长（1:23:45）+ 23:10 开始 + 距上次喂奶 + 「结束」大按钮 | 未睡时显示「开始」；进行中常驻 |

约定：进行中的计时在 widget 上**常驻刷新**（Glance 定时更新）；深夜 widget 用暗色（与 App 暗色主题一致）。

## 6. Android 实现注记

- 画板 360×800 → Compose 按密度自适应，不写死像素；tokens 直接映射 `MaterialTheme.colorScheme` + 自定义扩展色
- 底部弹层：`ModalBottomSheet`；快捷档 chips 用 `FilterChip` 或自定义
- Widget：Glance 实现，三款对应三个 `GlanceAppWidgetReceiver`；计时刷新用 Glance 的状态更新 + `AlarmManager` 分秒级不现实——分钟级刷新即可
- 计时跨进程存活：前台服务 + 开始时间戳（进程被杀后按时间戳还原，见 PRD §8）
- 日历：月视图自绘（`LazyVerticalGrid` 7 列），色点数据来自当日记录类型聚合
